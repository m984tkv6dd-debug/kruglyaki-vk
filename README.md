# Кругляки — версия для VK Игр

Бои шариков с пистолетами и картами улучшений. Эта ветка — веб-сборка для мини-приложения ВКонтакте (ID 54883649), опубликованная через GitHub Pages:
https://m984tkv6dd-debug.github.io/kruglyaki-vk/

- `index.html` — игра (HTML5 Canvas)
- `vk-bridge.min.js` — VK Bridge 3.0.2
- `platform-vk.js` — мост игры к ВК (инициализация, межстраничная реклама не чаще раза в 3 минуты)
- `peerjs.min.js` — онлайн по коду комнаты (WebRTC)
